# Remaining Blockers — latest-fix (LF)

**Task ID:** LF-BLK · প্রতিটি বাধা: প্রকৃত কারণ + যা হলে খোলে + ব্যবহারকারীর করণীয়। কোনো সৎ-ব্যর্থতাকে “সমর্থিত” বলে ঢাকা হয়নি।

---

## B-1 — গাওয়া গান (sung vocals) ⛔ পরিবেশ-বাধিত

- **কারণ:** প্রোভাইডার-শূন্যতা (কোড-ত্রুটি নয়): সব ভোকাল-সক্ষম API key+পেমেন্ট; লোকাল মডেল GPU-চাহিত; HF-Inference-এ lyrics-to-song নেই; keyless ACE-Step Space লাইভ-প্রোবে ব্যর্থ (`singing-provider-research.md`)।
- **খোলার শর্ত:** ① অনুমোদিত পেইড-API key (fal/Replicate-হোস্টেড ACE-Step 1.5 — MIT, ~$0.02/রান) অথবা ② ≥৬–৮GB VRAM GPU-যুক্ত মেশিন।
- **তারপরও বাধ্যতামূলক:** বাংলা গাওয়ার **লাইভ-যাচাই + মানব-শ্রবণ** — কোনো প্রার্থীর ক্যাটালগে বাংলা-গাওয়ার প্রমাণ নেই।
- **আপাতত সিস্টেম সৎ:** ভুয়া গান নয়; `[PROCEDURAL_INSTRUMENTAL]`-লেবেল।

## B-2 — লিপ-সিঙ্ক (কথা ও গান) ⛔ পরিবেশ-বাধিত

- **কারণ (৪-মাত্রা, ২০২৬-১০-১৭ পুনঃযাচাইকৃত):** license আংশিক-বদলেছে (Wav2Lip এখনও একাডেমিক-কেবল; MuseTalk 1.5 MIT; SadTalker Apache-2.0) — **কিন্তু** provider (সব হোস্টেড API key+পেমেন্ট; SDK-তে নেই) + hardware (GPU নেই — MuseTalk ন্যূনতম ৪GB VRAM) + integration (অ্যাডাপ্টার নেই) বহাল।
- **খোলার শর্ত:** অনুমোদিত পেইড key (MuseTalk/LatentSync-শ্রেণির হোস্টেড, ~$0.05–0.14/রান) বা GPU।
- **তারপরও বাধ্যতামূলক:** বাংলা **কথার** লিপ-সিঙ্ক বেঞ্চমার্ক আগে; গাওয়ার জন্য আরও আলাদা বেঞ্চমার্ক (rhythmic-drift ঝুঁকি নথিভুক্ত)।
- **আপাতত সিস্টেম সৎ:** `LIP_SYNC_UNSUPPORTED` — সাবটাইটেল/মিক্স-বিকল্পকে কখনো লিপ-সিঙ্ক বলা হয় না।

## B-3 — Edge-নিউরাল বাংলা কণ্ঠ (bn-BD/bn-IN দেশীয় উচ্চারণ) ⛔ পরিবেশ-বাধিত

- **কারণ:** এই sandbox থেকে Edge TTS-এর WSS-endpoint 403 প্রদান করে (নীতি/নেটওয়ার্ক-পাশ; কোড প্রোটোকল-সঠিক)।
- **বর্তমান প্রশমন:** Google-Translate বাংলা কণ্ঠ সৎ-ফলব্যাক (লাইভ-প্রমাণিত) — তবে একক কণ্ঠ, লিঙ্গ/bn-BD-bn-IN উচ্চারণ-পার্থক্য নেই, অপ্রাতিষ্ঠানিক (SLA নেই)।
- **খোলার শর্ত:** ভিন্ন নেটওয়ার্ক-পরিবেশ (Edge অ্যাক্সেসযোগ্য) হলে চেইন স্বয়ংক্রিয়ভাবে আবার Edge-প্রাথমিক হবে — কোড-পরিবর্তন লাগবে না।

## B-4 — script-preserving বাংলা ASR (ভাষা-যাচাইয়ের স্বয়ংক্রিয় সর্টান্ধ) ⛔ প্রদানকারী-সীমা

- **কারণ:** z-ai ASR বাংলা কথা **চীনা অনুবাদে** ফেরত দেয় (২০২৬-১০-১৭ দুই-বার লাইভ-প্রোব) — বাংলা লিপিতে ট্রান্সক্রিপ্ট দেয় না।
- **প্রভাব:** bn-অডিওর ভাষা-স্ট্যাটাস সর্বোচ্চ `AUDIO_VALIDATION_ONLY` হতে পারে — সিস্টেম এটি সৎভাবে ঘোষণা করে (§1.4)।
- **খোলার শর্ত:** বাংলা-লিপি-সক্ষম ASR প্রদানকারী (যেমন Whisper-শ্রেণির মডেল হোস্টেড বা লোকাল) — এজেন্ট-নির্ভরতা নয়।

## B-5 — মানব-শ্রবণ/দর্শন-রিভিউ ⏳ অপেক্ষমাণ (অ-বাধা, প্রক্রিয়া-চাহিদা)
