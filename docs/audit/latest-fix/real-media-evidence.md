## Test B — বাংলা গাওয়া গান ⛔ BLOCKED (সৎ)

- **প্রকৃত বাধা:** এই পরিবেশে **কোনো sung-vocals প্রোভাইডার নেই**। LF-2-R গবেষণা (`singing-provider-research.md`): সব ভোকাল-সক্ষম হোস্টেড API (Suno-রিসেলার, Udio, Lyria, fal/Replicate-হোস্টেড ACE-Step/DiffRhythm) অ্যাকাউন্ট+key+পেমেন্ট চায় — অনুমোদিত credential নেই; লোকাল মডেলগুলো GPU-চাহিত এবং হালকাতম ACE-Step-এর ওজনই (≈৪.৭GB) sandbox-এর মোট RAM-এর চেয়ে বড়; HF Inference-এ lyrics-to-song মডেলই সেবাভুক্ত নয়; একমাত্র keyless প্রার্থী (ACE-Step 1.5 অফিসিয়াল HF Space) **দুইবার লাইভ-প্রোব করা হয়েছে — দুইবারই `event: error`**।
- **সিস্টেমের সৎ আচরণ (যাচাইকৃত):** “গান গেয়ে শোনাও”-ধর্মী অনুরোধে ভুয়া গান নয় — স্পষ্ট প্রকাশনা + `[PROCEDURAL_INSTRUMENTAL]`-লেবেল-করা বিকল্প। **ইনস্ট্রুমেন্টালকে গান বলা হয়নি** — প্রতিটি আর্টিফ্যাক্টে টোকেন-লেবেল।
- **যা হলে আনলক হয়:** ব্যবহারকারীর প্রদত্ত GPU (≥৬–৮GB VRAM) বা অনুমোদিত পেইড-API key → ACE-Step 1.5 (MIT) প্রাথমিক প্রার্থী — বাংলা-গাওয়ার **লাইভ-যাচাই বাধ্যতামূলক শর্ত** (মডেলের ভাষা-তালিকায় বাংলা গাওয়ার প্রমাণ নেই)।

## Test D — সম্পূর্ণ মিউজিক ভিডিও ✅ লাইভ-সম্পন্ন (একই রান)

- **অডিও:** প্রসিডিউরাল ইনস্ট্রুমেন্টাল (৬৮ BPM, ৩৪ বিট-মার্কার) — **সৎ লেবেলসহ**: `musicEngine: "procedural_instrumental"`, নোট: “পরীক্ষামূলক… নিউরাল মিউজিক-মডেল নয়, গাওয়া কণ্ঠ নয়” + `[PROCEDURAL_INSTRUMENTAL]` টোকেন। আপলোড-গানের পথও রান্না-প্রস্তুত (measured বিট-বিশ্লেষণ) — এই রানে ব্যবহৃত হয়নি।
- **ভিডিও + ফাইনাল রেন্ডার:** Test C-সারণির মতোই।
- **মেটাডেটা/UI স্ট্যাটাস:** আর্টিফ্যাক্ট-মেটা সম্পূর্ণ সততা-স্তরে (`honestLabel: "সব 3টি শট প্রকৃত AI (cogvideox-3)"`, `avSyncOk: true`, `subtitles: false`); ব্রাউজারে কার্ড ৩টি আর্টিফ্যাক্ট-থাম্বনেইলসহ (অডিও/ভিডিও/পরিকল্পনা) রেন্ডার, console নির্ভুল।
- **লিপ-সিঙ্ক:** স্পষ্ট **অসমর্থিত** — মেটা `lipSync: false` + সীমা-নোট “লিপ-সিঙ্ক নেই — গায়কের মুখ নড়াচড়া বা গাওয়ার দাবি করা হয় না (§৫ সৎ-অবস্থা)।” **সাবটাইটেল/মিক্স-ভিত্তিক বিকল্পকে কখনো “লিপ-সিঙ্ক সম্পন্ন” বলা হয়নি।**
