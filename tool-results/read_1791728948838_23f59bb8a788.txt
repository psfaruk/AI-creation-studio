    80→## Agent execution loop (backend, JSON protocol)
    81→1. Context তৈরি: system prompt (role 'assistant') + সর্বশেষ ~20টি বার্তা (tool-result গুলো 'user' role-এ `[TOOL_RESULT] name ...` ফরম্যাটে)।
    82→2. LLM কল → parse: সম্পূর্ণ টেক্সট JSON `{"tool": "...", "arguments": {...}}` (বা ```json fence, বা প্রথম { … শেষ } ) হলে tool call, নাহলে final answer।
    83→3. Tool call: registry থেকে যাচাই (unknown tool / zod validation fail → structured error আবার LLM-কে) → tool_start emit → timeout-সহ execute → ফলাফল DB-তে → tool_end emit → ফলাফল context-এ append → ধাপ ২।
    84→4. MAX_STEPS = 8; ছাড়িয়ে গেলে "আর কোনো টুল ছাড়া এখনই চূড়ান্ত উত্তর দাও" নির্দেশনায় শেষ কল।
    85→5. Final answer → assistant Message + run finished → SSE 'message' + 'run_finished'।
